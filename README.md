# Link Tracer 0.4.0

This mod is a gameplay mod intended to fix a small issue that I personally had when making a helicopter, mainly targeted at composite logic nodes that are input or output.

It will, at its best ability will walk through logic nodes and wires and list where does it end. 
When you place a logic processor and click an already linked composite output, it will list all its channels. A screenshot from logic editor: <img width="758" height="729" alt="image" src="https://github.com/user-attachments/assets/4ff32faa-52a8-417c-bb47-1309998834d1" />
